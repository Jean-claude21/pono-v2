Call the Pono MCP tools: `find_project` with this folder's git remote (`git remote get-url origin`),
then `dev_status` for that project. Answer in a few lines: the server, the dev server's phase, the
preview address (as a link), the branch and the number of changed files. If the dev server is not
running, offer `start_dev`.
